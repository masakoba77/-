# 日本の社会保障

日本の社会保障給付費（年金・医療・介護・福祉等）の推移と、少子高齢化が国の財政に与える影響を公表データに基づいて解説する静的Webサイトです。

## 見る

依存パッケージ・ビルド不要の静的HTMLです。`index.html` をブラウザで開くか、任意の静的ホスティング（GitHub Pagesなど）にそのまま配置してください。

```
python3 -m http.server 8000
# http://localhost:8000 を開く
```

## 構成

- `index.html` — ページ本体・コンテンツ
- `assets/style.css` — スタイル（ライト/ダークモード対応）
- `assets/data.js` — 社会保障・予算データ（出典は本文末尾「データソース」を参照）
- `assets/charts.js` — 依存ライブラリなしのSVGチャート描画・ホバー表示・表切替
- `assets/disqus.js` — 掲示板（Disqus）埋め込み。利用するには `DISQUS_SHORTNAME` の設定が必要

## データについて

社会保障給付費は2022年度実績、国の一般会計予算（社会保障関係費）は令和8年度（2026年度）当初予算を基準としています。
「社会保障給付費」（保険料・公费を合算した給付総額）と「社会保障関係費」（国の一般会計における公费負担分のみ）は
集計範囲が異なるため、正確な数値・定義は各出典の一次資料をご確認ください。
