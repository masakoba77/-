# 日本の防衛費と予算

日本の防衛関係費の推移と、国の予算全体に与える影響を公表データに基づいて解説する静的Webサイトです。

## 見る

依存パッケージ・ビルド不要の静的HTMLです。`index.html` をブラウザで開くか、任意の静的ホスティング（GitHub Pagesなど）にそのまま配置してください。

```
python3 -m http.server 8000
# http://localhost:8000 を開く
```

## 構成

- `index.html` — ページ本体・コンテンツ
- `assets/style.css` — スタイル（ライト/ダークモード対応）
- `assets/data.js` — 予算データ（出典は本文末尾「データソース」を参照）
- `assets/charts.js` — 依存ライブラリなしのSVGチャート描画・ホバー表示・表切替

## データについて

数値は令和8年度（2026年度）当初予算を基準としています。集計範囲（防衛省予算のみか、NATO基準に準拠した広義の防衛関連予算か）によって数値が異なる場合があるため、正確な数値は各出典の一次資料をご確認ください。
